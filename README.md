# Производственный календарь

Библиотека классов на Java 21 и консольное приложение для работы с производственным календарём выбранного года. Модель учитывает рабочие дни, выходные, праздничные дни, предпраздничные сокращённые дни и отпуска.

## Возможности

- определение типа произвольного календарного дня;
- отображение календаря по месяцам с указанием типа каждого дня;
- подсчёт рабочих дней и рабочих часов за месяц;
- подсчёт рабочих дней и рабочих часов за квартал;
- подсчёт рабочих дней и рабочих часов за год;
- получение списка праздников года с указанием дней недели;
- учёт отпусков при определении типа дня и подсчёте рабочего времени.

## Модель

Основная модель представлена классом `ProdCalendar`, который хранит год календаря, список праздников и список отпусков.

Типы календарных дней описаны перечислением `DayType`:

- `WORKDAY` — рабочий день (8 часов);
- `WEEKEND` — выходной день;
- `HOLIDAY` — праздничный день;
- `SHORTENED_WORKDAY` — предпраздничный сокращённый рабочий день;
- `VACATION` — день отпуска.

Календарные правила представлены интерфейсом `CalendarRule`, который определяет методы проверки применимости правила к дате и получения типа дня.

Реализации интерфейса:

- `Holiday` — запись о праздничном дне с датой, названием и признаком возможности переноса;
- `Vacation` — период отпуска с начальной и конечной датами.

Исключения:

- `CalendarRuleException` — ошибка при обращении к дате, не относящейся к году календаря.

Для работы с датами используется `LocalDate` из `java.time`.
